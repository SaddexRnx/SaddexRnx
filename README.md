I'm Saddek Renane, an independent developer based in Algeria. I build things that solve real problems I run into, mostly around privacy, local-first tools, and making tech work for languages and contexts that mainstream tools ignore.

Most of my work falls into three buckets:

**Browser tools and privacy stuff.** [To_olT](https://github.com/SaddexRnx/toolt) is 175 file tools running entirely in your browser, no uploads. [TabBankruptcy](https://github.com/SaddexRnx/tabbankruptcy) saves your tab chaos without sending data anywhere. [Reddit Power Toolkit](https://github.com/SaddexRnx/redditpt) adds local-first workflows for Reddit.

**AI products.** [Plyrxio](https://github.com/SaddexRnx/Plyrxio) puts captions, translation, and video Q&A behind a one-line iframe. [KC](https://github.com/SaddexRnx/kchoupe) is a trilingual AI sales and support workspace built for North African commerce.

**Infrastructure.** [Algerian-wilayas](https://github.com/SaddexRnx/Algerian-wilayas) is open address data for all 58 wilayas, dairas, and 1,541 communes, with a React picker. [AI Tools Directory](https://github.com/SaddexRnx/sdxrnx-AI-Tools-Directory) maps thousands of AI tools into a browsable catalog.

If any of that sounds useful, the repos are all public. Reach me on [Telegram](https://t.me/saddex.x) if you want to talk.
